# คู่มือซ้อมแข่งขัน ทักษะการพัฒนาระบบประเมินบุคลากร (ปวช. 2569)

คู่มือนี้พาทีม 3 คน สร้างระบบประเมินบุคลากรตั้งแต่ศูนย์จนเสร็จภายใน 6 ชั่วโมง ทุกขั้นมี **คำสั่งที่ต้องพิมพ์ ไฟล์ที่ต้องสร้าง และโค้ดเต็มทุกบรรทัด** ให้พิมพ์ตามได้ทันที

> โค้ดเฉลยที่ทำเสร็จแล้วอยู่ในโฟลเดอร์ `project` (อยู่ข้างโฟลเดอร์คู่มือนี้) ใช้เทียบเมื่อติดปัญหา โค้ดทุกไฟล์ในคู่มือตรงกับเฉลยทุกบรรทัด
> ทุกขั้นจบด้วยหัวข้อ **✔ ตรวจขั้น** ให้ทำครบทุกข้อก่อนไปขั้นถัดไป ถ้าไม่ผ่านให้ดู `15-แก้ปัญหาที่พบบ่อย`
> งานออกแบบส่วนที่ 1–3 อยู่ในโฟลเดอร์ `งานออกแบบ` (ไฟล์ `.drawio` เปิดด้วยโปรแกรม Draw.io และภาพ PNG)

## ระบบที่ต้องทำ

มีผู้ใช้ 3 บทบาท

| บทบาท | ชื่อในโค้ด | ทำอะไร |
|---|---|---|
| ฝ่ายบุคลากร | `admin` | เพิ่มผู้ใช้ สร้างรอบ หัวข้อ ตัวชี้วัด มอบหมายกรรมการ ติดตามสถานะ ออกรายงาน |
| ผู้รับการประเมิน | `evaluatee` | ประเมินตนเอง เพิ่มรายละเอียด แนบหลักฐาน ดูความก้าวหน้า ดูความเห็นกรรมการ |
| กรรมการผู้ประเมิน | `evaluator` | ดูหลักฐาน ให้คะแนน บันทึกร่าง ลงนาม ยืนยันผล |

เครื่องมือที่ใช้ (ตรงกับข้อกำหนดของการแข่งขัน)

- **ฐานข้อมูล** MySQL 8 + phpMyAdmin (รันใน Docker)
- **Back-end** Node.js 24 + Express 5 + mysql2 + jsonwebtoken + bcryptjs + multer + cors
- **Front-end** Vue 3 + Vite + Vuetify 3 + Vue Router + Axios + @mdi/font + html2pdf.js
- **ออกแบบ** Draw.io แบบ Offline
- **ส่งงานร่วมกัน** Git + GitLab Server
