# 15 แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| `port is already allocated` / `EADDRINUSE` | มีโปรแกรมอื่นใช้พอร์ตอยู่ | ดูด้านล่าง "พอร์ตถูกใช้" |
| `Cannot connect to the Docker daemon` / `error during connect` | Docker Desktop ยังไม่เปิด | เปิด Docker Desktop รอจนไอคอนเป็นสีเขียว |
| back-end ขึ้น `ECONNREFUSED` ต่อฐานข้อมูลไม่ได้ | MySQL ยังเปิดไม่เสร็จ | `docker compose restart backend` หรือรอ 30 วินาที |
| `Cannot find module 'express'` | ยังไม่ได้ `npm install` | `docker compose exec backend npm install` หรือ `cd backend && npm install` |
| แก้โค้ดแล้วไม่เปลี่ยน | nodemon / Vite จับการแก้ไฟล์ไม่ได้ | ตรวจว่ามี `-L` ใน nodemon และ `usePolling` ใน vite.config.js หรือ `docker compose restart` |
| API ตอบ 401 | ไม่ได้ส่ง token หรือ token หมดอายุ | login ใหม่ ตรวจ Header `Bearer <token>` (มีเว้นวรรค) |
| API ตอบ 403 | บทบาทไม่ตรง หรือยังไม่เปลี่ยนรหัสผ่าน | ใช้บัญชีที่ถูกบทบาท / เปลี่ยนรหัสก่อน |
| หน้าเว็บขึ้น CORS error | เรียก `http://localhost:3000` ตรง ๆ | ให้เรียก `/api/...` ผ่าน proxy และตรวจ `API_URL` ใน docker-compose |
| หน้าเว็บขาว Console ขึ้น `Failed to resolve import` | ไฟล์ที่ import ยังไม่มี หรือสะกดผิด | สร้างไฟล์หน้า (ดูขั้น 5.13) ตรวจตัวพิมพ์เล็กใหญ่ |
| ภาษาไทยเป็น `???` | ไฟล์ .sql ไม่ได้บันทึกเป็น UTF-8 หรือใช้ MySQL รุ่นเก่า | ใน VS Code มุมขวาล่างต้องเป็น `UTF-8`, ใช้ image `mysql:8.4` (ค่าเริ่มต้นเป็น utf8mb4) แล้ว `docker compose down -v` และ up ใหม่ |
| อัปโหลดไฟล์ได้ 400 | ชนิดไฟล์ไม่อยู่ในรายการที่อนุญาต หรือใหญ่เกิน | ใช้ PDF/JPG/PNG ไม่เกินขนาดที่ตั้งใน upload.js และตรวจว่าชื่อช่องคือ `file` |
| อัปโหลดแล้วไฟล์หายหลัง restart | ไม่ได้ map โฟลเดอร์ `uploads` | โฟลเดอร์ `./backend` ถูก mount อยู่แล้ว ห้ามลบโฟลเดอร์ `uploads` |
| `npm create vite` ถามคำถามเยอะ | ใช้ npm เวอร์ชันใหม่ | เลือก `Vue` → `JavaScript` |
| login ด้วยรหัสในคู่มือแล้วได้ 401 ทั้งที่พิมพ์ถูก | ฐานข้อมูลมีผู้ใช้เก่าค้างจากการรันครั้งก่อน (seed ใช้ `INSERT IGNORE` ไม่เขียนทับ) หรือเคยเปลี่ยนรหัสไปแล้ว | ลองรหัสที่เปลี่ยนไว้ (เช่น `newpass123`) หรือรีเซ็ตแบบ "เริ่มใหม่หมดแบบสะอาด" ด้านล่าง |
| เปิดเว็บแล้วเห็นหน้าตาของงานเวอร์ชันอื่น | เคยรันโปรเจกต์อื่นที่ใช้พอร์ตเดียวกันค้างไว้ | ไปที่โฟลเดอร์โปรเจกต์เก่าแล้ว `docker compose down` ก่อน หรือดูใน Docker Desktop ว่า container ไหนเปิดอยู่ |
| ผู้รับการประเมินกดบันทึกคะแนนไม่ได้ ขึ้น "กรรมการประเมินแล้ว..." | ถูกต้องตามระบบ กรรมการบันทึกร่างหรือยืนยันผลไปแล้ว | ถ้ากำลังซ้อม ให้รีเซ็ตฐานข้อมูลแล้วทำตามลำดับ ผู้รับกรอกให้เสร็จก่อนกรรมการเริ่ม |
| ผู้รับการประเมินไม่เห็นคะแนนกรรมการ แต่ admin เห็น | ถูกต้องตามระบบ ผู้รับเห็นเฉพาะผลที่กรรมการกด "ยืนยันและส่งผล" แล้ว | ให้กรรมการกรอกคะแนนครบ เขียนความเห็น แนบลายเซ็น แล้วกดยืนยัน |
| `git push` ถามรหัสผ่านแล้วไม่ผ่าน | GitLab ต้องใช้ Access Token | GitLab → Preferences → Access Tokens สร้างแล้วใช้แทนรหัสผ่าน |

## พอร์ตถูกใช้

```powershell
# Windows ดูว่าใครใช้พอร์ต 3000
netstat -ano | findstr :3000
taskkill /PID <เลข PID> /F
```

```bash
# macOS / Linux
lsof -i :3000
kill <PID>
```

หรือเปลี่ยนพอร์ตฝั่งซ้ายใน docker-compose.yml เช่น `"3001:3000"`

## เริ่มใหม่หมดแบบสะอาด

ใช้เมื่อฐานข้อมูลเพี้ยนจนแก้ไม่ไหว (ข้อมูลทั้งหมดจะหาย)

```bash
docker compose down -v
docker compose up -d
docker compose logs -f backend
```

## ดู log เมื่อไม่รู้ว่าพังตรงไหน

```bash
docker compose ps                 # ตัวไหนไม่ Up
docker compose logs backend       # ดู error หลังบ้าน
docker compose logs frontend      # ดู error หน้าบ้าน
docker compose exec db mysql -uroot -proot1234 evaluation -e "SHOW TABLES;"
```

phpMyAdmin เปิดที่ `http://localhost:8080` (ผู้ใช้ `root` รหัส `root1234`)
