# 01 ติดตั้งโปรแกรมและเตรียมเครื่อง (ทุกคน)

ทำครั้งเดียวก่อนซ้อม เครื่องละ 1 รอบ (ทีมละ 3 เครื่อง, Windows 10 ขึ้นไป)

## 1. โปรแกรมที่ต้องมี

| โปรแกรม | ใช้ทำอะไร | คำสั่งติดตั้ง (PowerShell แบบ Administrator) |
|---|---|---|
| VS Code | เขียนโค้ด | `winget install Microsoft.VisualStudioCode` |
| Node.js 24 (LTS) | รัน npm บนเครื่อง | `winget install OpenJS.NodeJS.LTS` |
| Git | ส่งโค้ดเข้า GitLab | `winget install Git.Git` |
| Docker Desktop | รัน MySQL / phpMyAdmin / Node | `winget install Docker.DockerDesktop` |
| Draw.io Desktop | วาดผังงาน ฐานข้อมูล หน้าจอ | `winget install JGraph.Draw` |
| HeidiSQL หรือ DBeaver | ดู/แก้ฐานข้อมูล (ไม่บังคับ มี phpMyAdmin แล้ว) | `winget install HeidiSQL.HeidiSQL` |

> ถ้าใช้ `winget` ไม่ได้ ให้ดาวน์โหลดจากเว็บของโปรแกรมนั้นแล้วกด Next ไปเรื่อย ๆ
> Docker Desktop ต้องเปิด WSL 2 ถ้าโปรแกรมถามให้กด OK แล้ว **Restart เครื่อง**

## 2. ตรวจว่าติดตั้งครบ

ปิด PowerShell แล้วเปิดใหม่ จากนั้นพิมพ์ทีละบรรทัด

```bash
node -v            # ต้องได้ v24.x.x ขึ้นไป
npm -v             # ต้องได้ 10 ขึ้นไป
git --version
docker --version
docker compose version
```

เปิดโปรแกรม Docker Desktop ค้างไว้ (ไอคอนวาฬมุมขวาล่างต้องเป็นสีเขียว / Engine running) แล้วทดสอบ

```bash
docker run --rm hello-world
```

ถ้าเห็นข้อความ `Hello from Docker!` แปลว่าพร้อมใช้งาน

## 3. ดาวน์โหลด Docker Image ไว้ก่อน (สำคัญ: วันแข่งอาจไม่มีอินเทอร์เน็ต)

```bash
docker pull mysql:8.4
docker pull phpmyadmin:5
docker pull node:24-alpine
```

## 4. ติดตั้ง Extension ของ VS Code

พิมพ์ใน PowerShell ได้เลย (หรือกดไอคอน Extensions ใน VS Code แล้วค้นหาชื่อ)

```bash
code --install-extension Vue.volar                      # Vue - Official (สีและตรวจโค้ด .vue)
code --install-extension hollowtree.vue-snippets         # Vue 3 Snippets
code --install-extension sdras.vue-vscode-snippets       # Vue VSCode Snippets
code --install-extension christian-kohler.npm-intellisense
code --install-extension christian-kohler.path-intellisense
code --install-extension dbaeumer.vscode-eslint          # ESLint
code --install-extension esbenp.prettier-vscode          # Prettier - Code formatter
code --install-extension mikestead.dotenv                # DotENV
code --install-extension rangav.vscode-thunder-client    # Thunder Client (ทดสอบ API)
```

Extension "VS Code for Node.js" ตามรายการของการแข่งขัน ให้ค้นหาชื่อนี้ในแท็บ Extensions แล้วกด Install ส่วน Git มีมาใน VS Code อยู่แล้ว (แท็บ Source Control)

ตั้งค่าให้จัดรูปแบบโค้ดอัตโนมัติ: `Ctrl + ,` → ค้นหา `format on save` → ติ๊กถูก → ค้นหา `default formatter` → เลือก Prettier

## 5. ตั้งชื่อผู้ใช้ Git (ทำครั้งเดียว)

```bash
git config --global user.name "ชื่อ นามสกุล"
git config --global user.email "อีเมลที่ใช้ใน GitLab"
```

## 6. คำสั่งที่จะใช้บ่อย

| คำสั่ง | ความหมาย |
|---|---|
| `docker compose up` | เปิดทั้งระบบ (ดู log ในหน้าต่าง) กด `Ctrl + C` เพื่อหยุด |
| `docker compose up -d` | เปิดแบบเบื้องหลัง |
| `docker compose down` | ปิดทั้งระบบ (ข้อมูลในฐานข้อมูลยังอยู่) |
| `docker compose down -v` | ปิดและ **ลบข้อมูลฐานข้อมูลทิ้ง** (เริ่มใหม่หมด) |
| `docker compose logs -f backend` | ดู log ของ backend |
| `docker compose exec backend npm test` | รันทดสอบใน container |
| `docker compose restart backend` | รีสตาร์ต backend |
